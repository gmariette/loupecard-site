# Site de LoupeCard

Pages publiques de l'app LoupeCard : accueil, politique de confidentialité, assistance (français et anglais).

- Modifier les textes dans `construire.py`, le style dans `style.css`.
- Aperçu local : `python3 construire.py` puis ouvrir `public/fr/index.html`.
- Chaque push sur `main` publie le site sur GitHub Pages (`.github/workflows/publier.yml`).
